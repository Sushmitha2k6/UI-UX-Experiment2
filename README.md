# EXPERIMENT–2

19CS549 – UI & UX DESIGN
Title: Applying Gestalt Principles, Mobile UI Components, Interaction Behaviors & Brand Logo Design

## AIM

To design an effective mobile/web interface by applying Gestalt principles, using appropriate UI components and design patterns, ensuring smooth interaction behaviors, and creating a simple brand logo that aligns with usability and accessibility standards.

## ALGORITHM

(Write as steps – this is what examiners expect)

Step 1 – Identify User Needs

Understand the target users and actions (view events, register, explore case studies).

Define the core functions: Home, Events, Register, Profile.

Step 2 – Apply Gestalt Principles

Proximity:
Group related components (menu items, event details, profile settings) close together.

Similarity:
Use consistent colors, icons, and typefaces for similar actions (all primary buttons same color).

Continuity:
Arrange content in a smooth flow (vertical scroll on mobile, grid on website).

Figure–Ground:
Highlight important elements (events, CTAs) using contrast while keeping background subtle.

Closure:
Use card-style containers to present complete, visually closed sets of information.

Step 3 – Choose UI Components & Layout

Add Hero Area with search and featured event.

Use card layouts for case studies and event listings.

Implement bottom navigation (Home, Events, Register, Profile).

Add form pattern for user registration.

Use progressive disclosure (Show More → full details on tap).

Use modal popups for alerts & confirmations.

Step 4 – Define Interaction Behaviors

Use mobile-first responsive layouts.

Apply affordance: buttons look clickable, fields look editable.

Provide feedback: hover/tap states, success/error messages.

Maintain consistency in colors, typography, and icons.

Prevent errors with inline validations (email, phone, password).

Ensure accessibility, color contrast, readable fonts, ARIA labels.

Step 5 – Design the Brand Logo (in Canva)

Select minimal, flat style.

Use a child figure with a shield for safety.

Apply Blue + Yellow color scheme (trust + positivity).

Use clean sans-serif fonts.

Export logo in formats suitable for favicon, app icon, and prints.

Step 6 – Build the Final UI Mockups

Arrange all sections visually.

Apply selected color theme and typography.

Align with the principles defined above.

Step 7 – Evaluate the Design

Check consistency, readability, spacing.

Verify all components meet usability and accessibility guidelines.
